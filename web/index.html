ESP32-S31 1G Ethernet iperf 웹 플래셔

ESP32-S31-Function-CoreBoard-1 1G 이더넷(RGMII, YT8531) iperf 시험 펌웨어를 브라우저에서 바로 굽습니다. 데스크톱 Chrome이나 Edge에서 사용하세요.

이 브라우저는 Web Serial을 지원하지 않습니다. 데스크톱 Chrome이나 Edge로 열어 주세요.

ESP-IDF는 ESP32-S31을 스텁 없이 굽습니다(--no-stub). 이 방식이 기본값입니다. 해제하면 esptool-js의 스텁을 써서 더 빨리 굽고 전체 지우기도 쓸 수 있습니다.

0%

사용 순서

  1. 보드의 USB-UART Type-C 포트를 PC에 연결합니다.
  2. 1. 연결을 누르고 보드의 COM 포트를 고릅니다. 칩이 ESP32-S31인지 확인합니다.
  3. 버전을 고르고 2. 플래시를 누릅니다. 끝나면 보드가 자동으로 리셋됩니다.
  4. 연결되지 않으면 Boot 버튼을 누른 채 Reset 버튼을 눌렀다 떼서 다운로드 모드로 들어간 뒤 다시 연결합니다.
