ESP32-S31 1G Ethernet iperf Web Flasher

Flash the ESP32-S31-Function-CoreBoard-1 1G Ethernet (RGMII, YT8531) iperf test firmware straight from the browser. Use desktop Chrome or Edge.

This browser does not support Web Serial. Please open this page in desktop Chrome or Edge.

ESP-IDF flashes the ESP32-S31 without the stub (--no-stub), so this is the default. Unchecking it uses the esptool-js stub, which flashes faster and enables full-chip erase.

0%

How to use

  1. Connect the board's USB-UART Type-C port to the PC.
  2. Click 1. Connect and pick the board's COM port. Check that the chip is an ESP32-S31.
  3. Pick a version and click 2. Flash. The board resets automatically when done.
  4. If it does not connect, hold the Boot button, press and release Reset to enter download mode, then connect again.

Log

merged.bin is a single image of the bootloader, partition table and app, written from 0x0. Binaries are built automatically with ESP-IDF v6.1 on GitHub Releases. Source: firepooh/esp32s31-eth1g-iperf. Flashing engine: esptool-js.
